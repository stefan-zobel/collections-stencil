# Generated Example Classes

The classes below [`java/`](java) are **generated**: every template of the generator,
instantiated for all of its type combinations into the example package `net.generated.example`
(the functional interfaces into `net.generated.example.function`). They are checked in so that
you can read the code that the annotation processor or the command line generator produces,
without building the project.

Do not edit these files. The first line of each file names the template it comes from
(`generator/src/main/resources/net/collections/stencil/generator/templates/`); change the
template instead. The build of the `core` module regenerates this directory: it writes only the
files whose content changed and deletes files that are no longer generated, so a change to a
template shows up as a diff here.

In your own project you choose the classes, their package, and their visibility with the
annotations (see the [README](../../../README.md)); the generated code is the same.

The example classes are the test bed and the benchmark subject of this project. They are not
published as an artifact.
